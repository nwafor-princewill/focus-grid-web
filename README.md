## ✨ Features
- **Dynamic Routing:** Seamless navigation using `react-router-dom`.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop views using Tailwind CSS.
- **Interactive UI:** Smooth animations and intersection observers for a premium user experience.
- **Talent Pipeline:** Integrated application flow for interns and project collaboration for brands.

## 🛠️ Tech Stack
- **Frontend:** React.js, TypeScript
- **Styling:** Tailwind CSS
- **Routing:** React Router DOM
- **Deployment:** Vercel
- **Icons & Assets:** Custom SVG illustrations and optimized imagery

## 🚀 Getting Started

### Prerequisites
- Node.js (v16 or higher)
- npm or yarn

### Installation
1. **Clone the repository:**
   ```bash
   git clone [https://github.com/nwafor-princewill/focus-grid-web.git](https://github.com/nwafor-princewill/focus-grid-web.git)

   Install dependencies: npm install
   Run the development server: npm run dev

   📂 Project Structure
   ├── src
│   ├── assets         # Images, fonts, and icons
│   ├── components     # Reusable UI components (Footer, Navbar, etc.)
│   ├── pages          # Page views (Home, About, Contact, etc.)
│   └── App.tsx        # Main application logic & routing
├── vercel.json        # Deployment configuration for SPAs
└── tailwind.config.js # Custom styling configurations
